HOW IT WORKS

整理这件事，不必再从空白开始

  1. 01

    提供材料

    粘贴或导入聊天材料后，先确认材料里的姓名分别是谁；只有单独上传的聊天截图需要说明消息通常在左侧还是右侧，不必先替系统总结。

  2. 02

    获得整理结果

    千问根据已有素材整理关系、人设、经历和表达方式；零碎但有依据的内容也会保留，不要求先回答问卷。

  3. 03

    按需查看与修订

    列表和星图连接同一份档案。需要纠错时，找到具体条目，查看依据、适用人物和阶段，再修改。

  4. 04

    导出带走

    导出可读 Markdown、结构化 JSON 和重新对齐提示词，在目标平台中实际复测。
