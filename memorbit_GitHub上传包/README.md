# 星迹 Memorbit

将AI陪伴中的零散聊天与资料整理成可核对、可修订、可导出的角色与记忆档案，让用户看清哪些信息有依据、哪些需要确认，以及如何在目标平台实际使用。

本仓库整理自本人提供的 `memorbit-3.3.7-beta-B08-upload.zip`，公开的是前端部署快照，不包含模型后端、完整开发历史或历史测试套件。该部署包不能单独证明线上当前版本或全部模型能力。

![星迹界面](docs/screenshots/home.png)

## 我负责的部分

独立完成需求梳理、信息结构、视觉与交互设计、AI辅助实现与部署，并通过用户试用推动迭代。重点是将模糊的“想保留共同经历”拆成材料输入、内容整理、人工修订、导出与实际使用的任务链路。

## 关键能力

- 提供文字、截图及文档等材料，区分人物、来源和不确定信息。
- 按角色、关系、经历、背景和相处边界组织档案，支持修订与冲突处理。
- 以可读材料及结构化文件导出；不同平台的使用条件和迁移边界分别说明。
- 本机草稿、项目备份、长文本分段处理，以及参与者核对材料的导出与回收。

代码中已有这些前端入口，但AI整理依赖另外部署的后端。公开副本默认不连接原项目的线上服务。

## 快速预览

需要Node.js 18或更新版本，无需安装依赖：

```bash
npm start
```

打开 `http://127.0.0.1:8080`。可浏览界面，使用内置匿名示例及相应本地操作。AI整理、图片识别等请求在未配置后端时会显示提示，不会发送给原项目服务。

如需接入自己的后端，在 `config.js` 中设置：

```js
window.MEMORBIT_CONFIG = { apiUrl: 'https://your-backend.example/memorbit-ai' };
```

模型提供方密钥应保存在后端，不写进前端文件。后端需要匹配 `app.js` 中的请求与响应约定，并自行实现鉴权、额度和跨域等配置；本仓库未提供后端服务。

## 建议先看

| 文件 | 关注点 |
|---|---|
| `index.html`、`styles.css` | 页面、任务流程与视觉表达 |
| `app.js` | 材料导入、整理、修订、导出与异常反馈 |
| `archive-model.js` | 档案结构、验证与恢复逻辑 |
| `context-memory.js` | 情境记忆与参与者核对数据结构 |
| `large-text.js` | 长文本与本机任务存储 |
| `participant-review/` | 核对材料页面与回传处理 |

## 用户验证与边界

本人新版试用记录中，12人里有10人独立完成导出并在目标平台使用。该结果说明该批用户的任务完成情况，不等同于内容准确率、留存或付费价值；不同批次不是严格A/B。

本仓库不附真实聊天、用户备份、模型密钥或试用原始资料。代码内演示材料为匿名虚构示例。文档中的历史检查记录仅用于追溯来源，不视为本次重新完成的模型质量验证。
